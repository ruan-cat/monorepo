# 插件市场变更加固

AI 插件市场规则属于专项发布知识，不是通用 AI 记忆模板内容。只有维护插件市场的仓库，才可以在项目级 AI 记忆中保留简短入口；通用模板和一般项目的 AI 记忆文档不得包含这类章节。专项细则应由 `release-ai-plugins` 等发布技能和本参考资料维护。

## 适用边界

当变更涉及 marketplace、plugin manifest、平台安装说明或插件发布时，先建立“客户端 → marketplace → plugin manifest → 已发布组件 → 安装/更新/卸载文档 → 真实验证命令 → 清理动作”的映射。共享 skills 可以复用，但每个客户端的 schema、字段、相对路径和安装命令独立维护；禁止把 Claude Code、Cursor 或 Codex 的 hooks、commands、agents 或路径假设互相复制。

## 客户端映射

| 客户端      | 必须核对的维护入口                                          | 用户入口与真实验证                                           |
| ----------- | ----------------------------------------------------------- | ------------------------------------------------------------ |
| Claude Code | marketplace 条目、`.claude-plugin/plugin.json`、发布版本    | 安装、更新、卸载文档；使用对应 CLI 或官方安装流程 smoke test |
| Cursor      | marketplace 条目、`.cursor-plugin/plugin.json`、发布版本    | 安装、更新、卸载文档；使用对应 CLI 或官方安装流程 smoke test |
| Codex       | marketplace 条目、`.codex-plugin/plugin.json`、平台允许字段 | 安装、更新、卸载文档；使用对应 CLI 或官方安装流程 smoke test |

字段是否同名不构成可复制的依据。先查目标客户端 schema，再决定 manifest 与 marketplace 的表达方式；对外文档中的路径、命令和示例必须从用户的安装视角书写，不能暴露 monorepo 内部开发路径。

## 同步范围

规则写入与实际发布都必须同时覆盖维护入口和用户入口：市场与 manifest、各平台 README、总览安装文档、CHANGELOG，以及后续发版 skill 的同步清单。若规则只适用于某个插件仓库，应把它保留在该仓库的项目级入口和专项发布资料中，而不是加入通用 `init-ai-md` 模板。

## 验证与清理门禁

1. 先解析 JSON 并运行 schema、字段和版本一致性检查；这只是前置门禁。
2. 再使用目标客户端的真实 CLI 或官方验证路径完成安装 smoke test；静态校验通过不等于用户可安装。
3. 测试期间临时添加的 marketplace 或插件，必须执行对应的 remove 命令，并检查本地没有残留。
4. 因环境、账号或客户端限制无法取得真实安装证据时，交付中必须标记为“未验证”，说明缺失证据；禁止将构建、JSON 解析或可见配置当作替代证据。

## 常见漂移与纠正

| 失败模式                               | 纠正动作                                                       |
| -------------------------------------- | -------------------------------------------------------------- |
| 将市场发布规则写入通用 AI 记忆模板     | 从模板移除；只在插件仓库项目级入口、发布技能和本参考资料维护。 |
| 复制另一个客户端的专属字段             | 回到目标客户端 schema，重建客户端映射后定向修改。              |
| 只同步 manifest 或只更新一个 CHANGELOG | 按维护入口与用户入口清单逐项核对，缺一项即不宣布发布完成。     |
| 以 JSON 解析成功代替安装验证           | 执行真实 CLI/官方路径；受阻时如实记录“未验证”。                |
| 临时安装后留下 marketplace 或插件      | 执行 remove 并检查无残留，才结束 smoke test。                  |
