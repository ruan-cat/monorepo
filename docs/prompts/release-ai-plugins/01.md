目前完整完善的处理链路如下：

1. `.gitattributes`：`* text=auto eol=lf`
2. `.editorconfig`：`end_of_line = lf`
3. `prettier.config.mjs`：`endOfLine: "lf"`（**禁止** `"auto"`，`"auto"` 在 Windows 上会保留/引入 CRLF）

5. 运行 `git add --renormalize .` 实现 git 索引与工作区按 `.gitattributes` 归一化；**改完 `.gitattributes` 后不跑这一步会持续幽灵修改**（参见 [阮喵喵笔记 #025](https://notes.ruan-cat.com/bug/025-gitattributes-must-use-renormalize/)），若有暂存差异需单独提交规范化。
